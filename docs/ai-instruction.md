# AI Development Instructions

## Git Workflow

### Manual Push to Trigger F-Droid Bot Update

```bash
# After making changes and updating version in build.gradle.kts and fdroid metadata

# Add all changes
git add .

# Commit with descriptive message
git commit -m "feat: fix GPS handling and image sharing crash
- Fix GPS coordinates reading from EXIF data
- Fix crash when sharing images from file managers
- Update to version 1.1.6 code 20

Generated by Mistral Vibe.
Co-Authored-By: Mistral Vibe <vibe@mistral.ai>"

# Create and push tag
git tag v1.1.6
git push origin master
git push origin v1.1.6
```

This will trigger the F-Droid bot to detect the new tag and build the updated version.

## Play Store Release

### Generate Signed AAB

The signing key should be in the root of the project directory. The key details should be configured as environment variables:
- `KS_PATH`: Path to the keystore file (e.g., `kompact-release.keystore`)
- `KS_PASS`: Keystore password
- `KS_ALIAS`: Key alias (e.g., `upload`)
- `KEY_PASS`: Key password

#### Build Commands

```bash
# Build signed AAB using environment variables for signing
export KS_PATH="./kompact-release.keystore"
export KS_PASS="your_keystore_password"
export KS_ALIAS="upload"
export KEY_PASS="your_key_password"

# Build the release AAB
./gradlew bundleRelease

# The signed AAB will be generated at:
# app/build/outputs/bundle/release/app-release.aab
```

#### Alternative: Build with explicit key parameters

```bash
# If you prefer to use command-line parameters instead of environment variables
./gradlew bundleRelease \
  -Pandroid.injected.signing.store.file=$(pwd)/kompact-release.keystore \
  -Pandroid.injected.signing.store.password=your_keystore_password \
  -Pandroid.injected.signing.key.alias=upload \
  -Pandroid.injected.signing.key.password=your_key_password
```

### Upload to Play Store

```bash
# Install Google Play upload tool if needed
pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib

# Or use the official bundletool
java -jar bundletool.jar upload \
  --bundle=app/build/outputs/bundle/release/app-release.aab \
  --credential=path/to/your/service-account.json \
  --application-id=com.kompact
```

## Version Management

### Version Update Checklist

1. Update `app/build.gradle.kts`:
   - `versionCode`: Increment by 1
   - `versionName`: Update to new version (e.g., "1.1.6")

2. Update `fdroid/metadata/com.kompact.yml`:
   - Add new build entry with versionName, versionCode, and commit
   - Update CurrentVersion and CurrentVersionCode

3. Update `CHANGELOG.md` if exists

## Troubleshooting

### F-Droid Bot Issues

- Ensure the commit hash in metadata.yml matches the actual commit
- Use `HEAD` for the latest commit in metadata.yml for testing
- F-Droid bot builds from the tagged commit, not from master
- Always push tags: `git push origin v1.1.6`

### Signing Issues

- Verify keystore file exists at the specified path
- Ensure all environment variables are set correctly
- Key alias must match the alias used when creating the keystore
- If using CI, configure secrets properly

## Parallel Updates (F-Droid + Play Store)

1. First, update code and version as described above
2. Commit and tag the release
3. Push to GitLab (triggers F-Droid bot)
4. Build signed AAB locally or in CI
5. Upload AAB to Play Store manually

This ensures both stores receive updates simultaneously with the same codebase.
